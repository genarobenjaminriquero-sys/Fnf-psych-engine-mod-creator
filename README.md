# FunkinCraft

Estudio nativo para Android que permite crear, probar y exportar mods en `.zip` compatibles con **Friday Night Funkin' Psych Engine 1.0.4 y 0.7.3**.

## Cómo descargar el APK desde GitHub (sin PC)

1. Ve a la pestaña **Actions** en la parte superior de este repositorio en GitHub.
2. Entra a la ejecución más reciente de **Build FunkinCraft APK** (espera a que tenga el check verde ✓).
3. Baja hasta la sección **Artifacts** y descarga **FunkinCraft-APK**.
4. Descomprime el archivo descargado en tu teléfono Android y abre `app-debug.apk` para instalar **FunkinCraft**.
